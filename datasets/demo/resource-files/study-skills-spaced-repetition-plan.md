# Study Skills: Spaced Repetition and Weekly Planning

**Catalog:** Study Skills / Productivity Learning Unit 006 (Global)  
**Use when:** You feel behind, cram before exams, or want a sustainable routine for technical courses.

---

## Intended learning outcomes

1. Design a **spaced repetition** schedule tied to real course deadlines.
2. Use **active recall** instead of passive re-reading.
3. Block time realistically with **time blocking** and buffer slots.
4. Rate **confidence** after each session to prioritize weak topics.
5. Connect habits to progress tracking in the **Educational Companion System**.

## Active recall (core method)

After each lecture or lab:

- Close notes and write **three questions** the material should answer.
- Answer from memory for five minutes; then check sources and mark gaps.
- Convert gaps into flashcards or one-line prompts (question front, answer back).

Passive highlight-rereading feels productive but weakly predicts exam performance. Active recall strengthens memory traces you will need under time pressure.

## Spaced repetition schedule (template)

| Interval after first study | Action |
|---------------------------|--------|
| Same day (evening) | 10-minute recall quiz |
| +1 day | Short recall + one new problem |
| +3 days | Mixed recall set |
| +7 days | Weekly review block |
| +14 days | Cumulative mixed topics |
| Pre-exam | Full timed practice test |

Adjust intervals shorter for formulas you miss twice in a row; longer for stable topics.

## Time blocking (example week)

| Day | Morning (90 min) | Afternoon (60 min) | Evening (30 min) |
|-----|------------------|--------------------|------------------|
| Mon | New lecture content | Lab / coding | Recall quiz |
| Tue | Problem set | — | Confidence log |
| Wed | Weak-topic repair | Group study | — |
| Thu | New lecture | Assignment | Spaced review |
| Fri | Project work | — | Weekly template |
| Sat | Optional deep dive | — | Rest |
| Sun | Plan next week | Light recall | Reflection |

Include **buffers**: one empty slot per day for overrun tasks.

---

## Confidence ratings

After each study block, rate 1–5:

- **5:** Could teach this topic today.
- **3:** Can solve standard problems with notes.
- **1:** Need structured re-learning.

Log ratings in a table:

| Topic | Date | Confidence | Next action |
|-------|------|------------|-------------|
| SQL joins | | | |
| Normal forms | | | |
| Control flow | | | |

Prioritize topics with confidence ≤ 2 in the next two days.

---

## Weekly review template

1. List topics touched this week.
2. Circle two that felt hardest.
3. Schedule one **mixed practice** session (interleave subjects).
4. Delete or archive completed cards; add cards for new gaps.
5. Write one sentence: *What worked? What to change?*

---

## Example routine for technical courses

**Databases week:** Mon–Tue new theory; Wed recall FDs and normal forms without notes; Thu lab SQL; Fri practice anomalies case; Sun 20-minute mixed quiz.

**Programming week:** Daily 15-minute trace-one-program exercise; two debugging journal entries; pair review on boundary cases.

**AI / data weeks:** One worksheet session (metrics or cleaning checklist); one communication paragraph for non-technical audience.
